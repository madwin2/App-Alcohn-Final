# SOP (esqueleto) · Registrar un Rehacer

> Workflow: [WF-08](../03-workflows/WF-08-rehacer.md)

1. Lo decide quien detecta la falla (normalmente Fede al probar en cuero, o Ventas por un reclamo).
2. Alcohn AI → Pedidos (o Producción) → Fabricación → **Rehacer** (no desde el menú del programa: ahí no se guarda el motivo).
3. Elegir motivo, describir, indicar si se cobra algo extra (monto y concepto).
4. Automático: el sello vuelve prioritario, se borra la foto (si estaba en Foto), el pedido vuelve a "Sin envío", se avisa a Producción, Ventas y **al cliente por WhatsApp**.
5. `[REQUIERE INFORMACIÓN DEL EQUIPO]` Si hay que re-vectorizar o corregir la medida.
6. Cargo extra: se cobra o no según de quién fue el error; se le informa el monto al cliente y lo paga. El aviso al cliente es intencional (transparencia).
