# SOP (esqueleto) · Envíos por Andreani

> Workflow: [WF-07](../03-workflows/WF-07-envio-andreani.md) · Integración: [andreani.md](../07-integrations/andreani.md)

1. Abrir el **túnel de la oficina** (quien lo necesite: vendedor o Julián).
2. Alcohn AI → Envíos → Andreani → revisar cuántos links hay disponibles → "Generar más" si hace falta — lo hacen los vendedores **antes de mandar las fotos**.
3. Al subir fotos, el link se envía solo al cliente con el último ítem.
4. No se despacha hasta que el cliente complete y pague el link.
5. "Traer etiquetas" → asignar huérfanas al pedido correcto; marcar erróneas. Si Andreani ya recibió paquetes que tenías en la lista, también pasan a Despachado y el cliente recibe el seguimiento.
6. Confirmar la venta (**Transferido**) → "Descargar" PDF unido.
7. Imprimir (Zebra ZD220), armar y embalar, llevar a la sucursal **Independencia** (central de Mar del Plata).
8. "Actualizar seguimientos" (si hace falta aparte de traer etiquetas) → los que Andreani ya recibió pasan a Despachado y el cliente recibe el seguimiento.
