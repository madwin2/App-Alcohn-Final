# SOP (esqueleto) · Enviar la foto y cobrar

> Workflow: [WF-05](../03-workflows/WF-05-foto-y-cobro.md)

1. Alcohn AI → Inicio → "Sellos listos → Enviar foto" (o Pedidos filtrando Hecho + Señado).
2. **Juli B** saca la foto de cada ítem apenas está Hecho (se manda por ítem). `[REQUIERE INFORMACIÓN DEL EQUIPO: estándar visual]`
3. Alcohn AI → Pedidos → "Subir fotos": cargar las fotos, asignar cada una a su ítem. Si hay pedidos Andreani y faltan links, generar más antes (Envíos → Andreani) o esperar.
4. Automático: el cliente recibe la foto con el monto restante.
5. Esperar el comprobante del cliente por WhatsApp (cobran Juli B y Cachi).
6. Al verificar el pago: Pedidos → Venta → **Transferido** (o cargar los datos de envío, que lo marca solo).
7. Si pasan 10 días sin pago, el sistema lo marca **Deudor**. Política deseada: recordatorio cada ~15 días (hoy **no** automatizado).
