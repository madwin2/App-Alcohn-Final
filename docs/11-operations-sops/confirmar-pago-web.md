# SOP (esqueleto) · Confirmar un pago web por transferencia

> Workflow: [WF-02](../03-workflows/WF-02-pedido-web.md)

1. Alcohn AI → Comercial Web → Potenciales → pedidos con pago pendiente (badge del menú).
2. Abrir el comprobante subido por el cliente.
3. `[REQUIERE INFORMACIÓN DEL EQUIPO]` Verificar el ingreso del dinero (qué cuenta, qué se chequea).
4. **Confirmar pago**: monto de seña recibido (la web cobra $30.000; si el checkout no lo informa el sistema propone $20.000 — revisar) y nombre del diseño.
5. Efecto automático: se crean los ítems, el pedido aparece en Pedidos y el cliente recibe la confirmación por WhatsApp.
6. `[REQUIERE INFORMACIÓN DEL EQUIPO]` Qué hacer si el comprobante no coincide.
