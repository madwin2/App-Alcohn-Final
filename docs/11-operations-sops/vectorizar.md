# SOP (esqueleto) · Vectorizar diseños

> Workflow: [WF-03](../03-workflows/WF-03-diseno-y-vectorizacion.md) · Módulo: [Vectorización](../02-modules/vectorizacion/README.md)

**Responsable**: Fede (con ayuda en picos de demanda) · **Frecuencia**: `[REQUIERE INFORMACIÓN DEL EQUIPO]`

1. Alcohn AI → Vectorización → **Pedidos**. (Activar "incluir Rehacer/Prioridad" si corresponde.)
2. Revisar cada imagen. Si está sucia o borrosa: clic derecho → copiar → retocar con IA (en general ChatGPT) → clic derecho → "Reemplazar desde el portapapeles".
3. Seleccionar (shift para rango), ajustar recorte si hace falta.
4. Verificar el **modo** (`production` cobra créditos; `test` gratis con marca de agua) y el saldo.
5. **Vectorizar** → confirmar.
6. Pestaña **Revisión**: por cada resultado, comparar antes/después → **Confirmar**, **Rechazar** o **Reemplazar con SVG propio**. Criterio: fiel al diseño, líneas rectas bien hechas, sin deformaciones. Revisa quien pidió el vector (normalmente Fede). No cerrar la pestaña hasta terminar.
7. Si aparece el popup de **medida de fabricación**: `[REQUIERE INFORMACIÓN DEL EQUIPO: criterio para aceptar la sugerida o ajustar]`.
8. Archivos difíciles para la automatización o con requisitos específicos: vectorizar a mano en **Illustrator** (a criterio de quien hace el vector), exportar SVG en mm y subirlo en Pedidos/Producción o "Asignar SVG".
