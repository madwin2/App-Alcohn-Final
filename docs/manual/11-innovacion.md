# 11. Innovación

[← Volver al índice](README.md)

Es el **tablero interno de ideas, mejoras y proyectos** de Alcohn ("Lab interno"). Sirve para reuniones rápidas y para el seguimiento diario de proyectos que no son pedidos. Se llega desde **Innovación** en el menú.

## Cómo está organizado

```
Área (columna del tablero)
 └─ Proyecto o idea
     └─ Tarea
         └─ Subtarea (checklist)
```

- **Área**: una columna del tablero. Agrupa proyectos por equipo, producto o iniciativa (por ejemplo, "Producción"). Tiene un color.
- **Proyecto**: una mejora o iniciativa. Tiene responsable, colaboradores, prioridad, estado, fecha límite y progreso.
- **Tarea**: una parte del proyecto, con su responsable, checklist, comentarios y adjuntos.

| Campo | Valores |
|---|---|
| Estado | Pendiente, En proceso, Esperando revisión, Bloqueado, Finalizado, Cancelado |
| Prioridad | Baja, Media, Alta, Crítica |

El **progreso** se calcula solo: el de una tarea es el porcentaje de subtareas hechas, y el de un proyecto sale de sus tareas.

## Crear

- **Nueva área**: **Nombre**, **Descripción** (opcional) y **Color** → **Crear área**.
- **Nueva idea** (botón de arriba): **Título**, **Área**, **Responsable**, **Prioridad** y **Estado** → **Guardar idea**.
- Dentro de una columna: **Proyecto** → escribí el **Nuevo proyecto / objetivo** y una descripción → **Guardar**.

## Trabajar un proyecto

Clic en un proyecto abre el **Detalle de proyecto**. Los cambios se guardan solos al modificar cada campo.

- Datos del proyecto, **Fecha límite**, responsable y **Colaboradores**.
- **Nueva tarea** / **Agregar tarea**.
- **Eliminar proyecto**: borra el proyecto y sus tareas. ⚠️ No se puede deshacer.

Clic en una tarea abre el **Detalle de tarea**:

- Checklist de subtareas (**Nueva subtarea** → **Agregar**).
- **Comentarios** (**Dejar comentario...** → **Comentar**).
- **Adjuntos**: imágenes, PDF u otros documentos de referencia (**Subir archivo**).
- **Historial de cambios**.

🤖 Las tareas asignadas a una persona le aparecen en **Mis tareas**, en su [Inicio](02-inicio.md#mis-tareas-innovación).

## Buscar y filtrar

**Filtros y búsqueda**: por texto (**Buscar por área, proyecto, tarea...**), área, responsable, estado y prioridad. Si no ves nada, tocá **Limpiar filtros**.
