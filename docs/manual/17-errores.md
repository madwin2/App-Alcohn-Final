# 17. Errores

Pantalla para ver los **rehaceres** del taller: cuántos hubo, por qué motivo, y qué archivos (base/vector) tenía el sello **cuando se marcó el error**.

## Dónde está

Menú lateral → **Errores** (`/errores`).

## Para qué sirve

- Ver métricas del período (este mes, últimos 90 días o todo): total, sin descripción, motivos, cobros, quién marcó.
- Filtrar por motivo (también tocando las barras) o ver solo los que faltan describir.
- Abrir un caso, **completar la descripción** y mirar/descargar la base y el vector **congelados**.

## Importante

Cuando marcás Rehacer en Pedidos o Producción, la app guarda una copia de los archivos. Después podés borrar o subir otro vector en el sello: **en Errores sigue la versión vieja** para poder analizar qué falló.

Los rehaceres de antes de esta función aparecen en la lista (motivo y fecha) pero pueden no tener archivos congelados.

## Cómo usarla

1. Elegí el período (este mes, 90 días o todo).
2. Tocá un motivo en las métricas o usá el filtro para ver solo ese tipo.
3. Si hay casos **sin descripción**, tocá esa card: se listan para completar.
4. En la tabla podés **cambiar el tipo de error** sin abrir el caso. También podés abrir el detalle para la descripción y los archivos.
5. Revisá/descargá la base y el vector **congelados** del momento del error.

## Cómo se registra un error

No se crea a mano en esta pantalla. Se crea cuando alguien elige **Rehacer** en fabricación y completa el motivo (ver [Pedidos](03-pedidos.md) / [Producción](06-produccion.md)). La descripción se puede dejar para después y completarla acá.
